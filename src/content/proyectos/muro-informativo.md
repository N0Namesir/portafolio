Muro Informativo es una biblioteca pública de recursos para aprender desarrollo de software. Cada recurso está clasificado con una taxonomía cerrada de 34 subtags, lo que permite filtrar de forma precisa por tema, nivel y formato.

## Características

- Base de datos en Supabase con taxonomía controlada.
- Filtrado por tags funcional en el sitio público.
- Sitio estático en producción, optimizado para carga rápida.
